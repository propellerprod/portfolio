# ПРОПЕЛЛЕР — Видеопродакшн (React + TypeScript + Vite)

Официальный сайт и интерактивное портфолио видеопродакшна **ПРОПЕЛЛЕР** (Москва × Орёл).

## ✨ Возможности

- **Интерактивное портфолио**: Динамическая фильтрация по категориям (Концерты, Блогеры, Клипы, Reels, Другое).
- **Плеер и детальный просмотр**: Встраивание видео через адаптивный iframe (YouTube, Rutube, VK Видео, VK Клипы, Vimeo) с поддержкой горизонтальных 16:9 и вертикальных Reels/Shorts 9:16 форматов.
- **Фотогалерея**: Просмотр дополнительных кадров и полноэкранный зум (Lightbox).
- **Услуги и цены**: Детальные карточки пакетов и плавающее превью услуг при наведении.
- **Панель управления (Админка)**: Управление проектами и коллаборациями, автополучение превью и метаданных из видео.
- **Атмосферный визуал**: Эстетика VHS (сканлайны, глитч, счетчик кадров и таймкод на 24 FPS), живое время Москвы, фоновое пленочное зерно, адаптивная типографика (Unbounded, Golos Text, JetBrains Mono).

## 🚀 Запуск и сборка

```bash
# Установка зависимостей
npm install

# Запуск сервера разработки (порт 3000)
npm run dev

# Сборка проекта
npm run build

# Запуск в продакшене
npm start
```
