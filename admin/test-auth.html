📋 Инструкция по созданию токена:

  1. Зайдите на https://github.com/settings/tokens
  2. Нажмите "Generate new token" → "Generate fine-grained personal access token"
  3. Token name: любое имя (например, "propeller-admin")
  4. Expiration: выберите срок действия (рекомендуется 90 дней)
  5. Repository access: выберите только propellerprod/portfolio
  6. Permissions → Contents: выберите Read and write
  7. Нажмите "Generate token"
  8. Скопируйте токен (начинается с github_pat_) и вставьте выше
