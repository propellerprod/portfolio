# Инструкция по использованию видео в портфолио (Rutube и VK Видео)

## 📋 Обзор функционала

Этот проект позволяет добавлять в портфолио видео с **Rutube** и **VK Видео** без скачивания файлов. Все видео встраиваются через iframe, а обложки (превью) получаются как ссылки на изображения.

---

## 🔧 Установка и настройка

### 1. Миграции базы данных
```bash
python manage.py makemigrations portfolio
python manage.py migrate
```

### 2. Запуск сервера разработки
```bash
python manage.py runserver
```

## 👨‍💼 Админ-панель

### Добавление проекта с видео

1. Перейдите в админ-панель: `http://localhost:8000/admin/`
2. В разделе **"Портфолио"** → **"Элементы портфолио"** нажмите **"Добавить"**
3. Заполните основные поля:
   - **Название проекта**
   - **Описание** (опционально)

4. В секции **"Видео"**:
   - **Ссылка на видео**: вставьте URL видео с Rutube или VK Видео
   - **Источник видео**: выберите Rutube или VK Видео (может определиться автоматически)
   - **Автоматически получать превью**: включите, если хотите использовать авто-превью

5. **Кнопка "📷 Получить превью из видео"**:
   - Нажмите эту кнопку после ввода ссылки на видео
   - Система автоматически получит URL обложки из API сервиса
   - Ссылка на превью будет вставлена в поле "Ссылка на обложку"
   - **Важно**: нажмите "Сохранить", чтобы сохранить ссылку на превью в базе данных

6. Настройте публикацию:
   - **Опубликовано**: включите для отображения на сайте
   - **Порядок отображения**: число для сортировки (меньшее = выше)

### Форматы ссылок на видео

#### Rutube:
- `https://rutube.ru/video/abc123def456/`
- `https://rutube.ru/play/embed/abc123def456/`
- `https://rutube.ru/videos/abc123def456/`

#### VK Видео:
- `https://vk.com/video-123456_789012345`
- `https://vk.com/video_ext.php?oid=-123456&id=789012345`

## 🔍 Как это работает

### Модель PortfolioItem

```python
class PortfolioItem(models.Model):
    title = CharField(...)              # Название проекта
    description = TextField(...)        # Описание
    video_url = URLField(...)           # Ссылка на видео (Rutube/VK)
    video_source = CharField(...)       # Источник: 'rutube', 'vk', 'other'
    thumbnail_url = URLField(...)       # Ссылка на обложку (URL, не файл!)
    use_auto_thumbnail = BooleanField() # Авто-получение превью
    image = ImageField(...)             # Дополнительное изображение
    is_published = BooleanField()       # Опубликовано ли
    order = IntegerField()              # Порядок сортировки
```

### API для получения превью

Функции в `video_utils/api.py`:

1. **`get_video_thumbnail(video_url)`** - универсальная функция
   - Автоматически определяет сервис (Rutube/VK)
   - Возвращает dict: `{'thumbnail_url': '...', 'service': '...', 'video_id': '...'}`

2. **`get_rutube_thumbnail(video_url)`** - для Rutube
   - Использует публичное API Rutube
   - Если API недоступно, генерирует URL по шаблону

3. **`get_vk_video_thumbnail(video_url)`** - для VK
   - Использует VK API метод `video.get`
   - Получает максимальное доступное изображение

4. **`get_embed_url(video_url)`** - для встраивания
   - Преобразует обычную ссылку в embed-ссылку для iframe

## 🔒 Важные замечания

### Про превью (обложки)
- ✅ Превью хранятся как **URL**, а не файлы
- ✅ Не занимают место на сервере
- ✅ Автоматически обновляются при изменении видео
- ⚠️ Требуется подключение к интернету для загрузки изображений

### Про видео
- ✅ Видео **не скачиваются** на сервер
- ✅ Встраиваются через iframe оригинального сервиса
- ✅ Воспроизведение происходит на стороне Rutube/VK
- ✅ Экономия трафика и места на сервере

### Про API
- Rutube API: `https://api.rutube.ru/api/video/{id}/`
- VK API: `https://api.vk.com/method/video.get`
- Для продакшена рекомендуется:
  - Добавить токен VK API для стабильной работы
  - Реализовать кэширование результатов API
  - Добавить обработку ошибок сети

### Кэширование превью

Для улучшения производительности добавьте кэширование:
```python
from django.core.cache import cache

def get_video_thumbnail_cached(video_url):
    cache_key = f'video_thumbnail_{video_url}'
    result = cache.get(cache_key)
    
    if result is None:
        result = get_video_thumbnail(video_url)
        cache.set(cache_key, result, timeout=3600)  # 1 час
    
    return result
```
